# ⚡ AlgoTester

> An interactive developer tool engineered to diagnose runtime errors, parse stack traces, and deliver clear, actionable code solutions across multiple programming languages.

🔗 **Live Application:** (https://sayandas404.github.io/Algorithm-Tester/)

---

## 📌 Problem & Overview

Debugging cryptic terminal error traces and runtime exceptions often interrupts workflow, especially when learning algorithms or testing new code snippets. 

**AlgoTester** bridges that gap by providing a clean, distraction-free interface where developers can paste an error trace or faulty snippet, understand what failed, and receive step-by-step diagnostic breakdowns alongside corrective code logic.

---

## ✨ Features

- **Multi-Language Error Parsing:** Diagnostic support for Python, JavaScript, and common algorithm runtimes.
- **Automated Breakdown:** Translates abstract compiler/interpreter errors into plain-language explanations.
- **Guided Fixes:** Suggests corrected code logic and syntax alternatives.
- **Quick Samples:** Pre-loaded common error templates (e.g., `IndexError`, `TypeError`) for instant testing and demonstration.
- **Responsive Dark Theme UI:** Built with modern CSS variables, intuitive input fields, and smooth state transitions.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Deployment:** GitHub Pages
- **Backend / Scripting:** Python (Logic evaluation & algorithm tests)
